NASA 3D Resources models are free to use; see NASA's media usage guidelines
(<https://www.nasa.gov/nasa-brand-center/images-and-media>). Use of the model does not imply NASA
endorsement.

`iss.glb` is the NASA file processed by `../../scripts/prepare_iss_model.py`: stray nodes removed,
ISS material colours, and a root transform to metres in the globe's body frame (x along velocity,
y cross-track, z zenith). The mesh data is unchanged.
